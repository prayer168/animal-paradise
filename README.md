# 動物王國大亨 v2.1 — Animal Paradise

直接用 Chrome 或 Edge 打開 `index.html`。需要網路載入 Three.js 與字型。
`animal-kingdom-tycoon/` 是壓縮檔原版備份，升級版入口位於本資料夾根目錄。

## 新玩法
- 祕密任務：每人隨機兩張，擲骰前按「任務」查看；先顯示交接提示。每項完成自動領 $2,000，每局僅發一次，計入總資產。結算顯示完成數。
- 拍賣：停在無主土地後不買，所有未破產玩家依序競標。底價為原價一半（向上取百），加價 $200，只用現金。退出不能重新加入；無人競標則流標。狐狸九折不適用拍賣。
- 交易：擲骰前按「交易」，可交換雙方各一塊土地與單向現金。設施隨土地轉移；送出前預覽、對方同意後成交。當前玩家每個自己的回合限成交一次。電腦會評估價格，且每三回合嘗試提出可補齊棲地的收購案。
- 主動技能：保留原有被動能力；第一回合可用，使用後隔三個自己的回合恢復，休息回合也算。手牌滿或不符合條件時不消耗技能。
- 10 回合短局：保留 $20,000 起始資金與總資產排名，預設開啟電腦快轉，可用 ⏩ 關閉。仍可選 20、30 回合或無限。

| 角色 | 主動技能 |
| --- | --- |
| 熊爺爺 | 森林補助：+$1,200 |
| 兔妹 | 靈巧計畫：一張遙控骰子 |
| 孔雀夫人 | 募款晚會：存款 8%，至少 $600、最多 $1,600 |
| 小猴 | 機關準備：一張路障卡 |
| 烏龜博士 | 研究靈感：下一次科學挑戰答對獎金加倍；不疊加 |
| 狐狸商人 | 精明建設：選一塊自己的土地，以折扣後升級費再減半，立即升一級 |

## 存檔
沿用原存檔鍵，舊存檔讀取時補上任務與技能資料。任務／技能／交易操作後儲存；輪流交接時也儲存。
選單只能在玩家擲骰前開啟，以避免動畫或付款途中存入不完整狀態。重新整理後，擲骰前的回合不會重複增加計數。
同機輪流的任務交接是畫面隱私提示，請其他玩家移開視線。

## 驗證
已安裝 Node.js 時執行 `node tests/gameplay.cjs`。
詳細測試範圍見 `TEST-REPORT.md`。

### Playwright 瀏覽器測試
1. `npm ci`
2. `npx playwright install chromium`
3. `npm run serve`
4. 在另一個終端機執行 `npm run test:browser`。

測試使用獨立瀏覽器環境，不會修改平常瀏覽器的存檔。包含完整 10 回合、交易、拍賣、六位角色技能、銀行與破產、存檔續玩、手機直向／橫向畫面、效能取樣與 GPU 資源回收。
測試截圖與 JSON 報告輸出至 `test-results/`，不提交到 Git。
可以用 `GAME_URL` 指定其他測試網址，用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定已安裝的 Chromium。

## 畫質與穩定性
- 🌿 輕量畫質：降低繪圖解析度、關閉陰影，適用較慢的電腦與平板；💎 可切換精緻畫質。
- 軟體繪圖環境預設使用輕量畫質，精緻模式持續慢幀時會自動降低畫質。手動選擇畫質後優先保留使用者選擇。
- 重建設施、棋子、路障及精靈時會釋放舊的幾何、材質與紋理資源。
- 移動與結算中停用規則／選單按鈕，避免中斷遊戲對話框；損壞或不相容的存檔會忽略。

## 臉書分享素材
`social/facebook.html` 提供中文版、英文版與中英合併版的一鍵複製，以及縮圖複製／下載。遊戲首頁已設定 Open Graph 分享圖片。
`npm run test:social` 驗證實際剪貼簿文字、圖片複製、下載、行動版與分享 metadata；執行前同樣需啟動本機伺服器。
