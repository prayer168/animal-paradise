# Facebook 發文素材

開啟 `facebook.html`，可一鍵複製中文、英文或中英合併貼文，亦可複製／下載縮圖。

- `thumbnail.png`：1733 × 907，約 1.91:1 的 Facebook 橫式縮圖，內建 ImageGen 製作的宣傳插畫。
- `facebook-zh.txt`：繁體中文貼文。
- `facebook-en.txt`：英文貼文，已註明遊戲介面為繁體中文。
- `facebook-bilingual.txt`：中英合併貼文。
- `thumbnail-prompt.txt`：實際圖片製作提示詞；參考專案的 `preview.png`，未取代遊戲內美術。

建議在 Facebook 貼上文案後，手動上傳 PNG，確保圖片與文字一起顯示。
中英文及合併貼文僅保留遊戲網址，不加入教材入口網站連結，以免 Facebook 選到其他網站的預覽。
遊戲首頁亦已設定 Open Graph 縮圖；平台既有的連結預覽快取可能需要重新擷取，實際顯示由 Facebook 決定。
